Install Termux

Termux is the app that runs the commands. Skip this step if you already have Termux installed from F-Droid or GitHub.

Get Termux
  1. Tap the button above. It opens the Termux page on F-Droid.
  2. Scroll down to the list of versions and find the first one at the top. Ignore the blue Download F-Droid button, it is not Termux.
  3. Under that version, tap Download APK, the link inside the red circle in the picture below. The word beta on it is normal.
  4. Open the downloaded file and tap Install. If Android asks, allow installing from this source.
  5. Open Termux once, then go to Setup.

Tap the link inside the red circle.
